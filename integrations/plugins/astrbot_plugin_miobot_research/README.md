# MioBot 网页检索与文件阅读

默认关闭，授权后可使用两个实际工具：`miobot_search_web`、`miobot_read_file`。
它们通过宿主认证桥访问应用服务，不接受模型指定任意URL、文件路径、用户或助手。

网页检索使用固定官方 Tavily Search API，与固定版 AstrBot 内置的 Tavily 适配器
采用同一服务契约。必须另外配置服务凭据；未配置时返回 `needs_configuration`，
不假装已联网。当前只读取该服务返回的摘要，不自动抓取任意来源页面；返回公开
来源链接与检索时间。服务与来源URL拒绝私有/回环/链路本地地址、异常域名解析、
重定向及超限响应。调用Tavily可能产生搜索服务费用。

原生文件抽取入口依赖额外 Moonshot API。为避免自动发送文件至新供应商，当前
改用运行包已有的 `pypdf` 与 `python-docx` 在本地解析。支持 TXT、MD、PDF、DOCX，
每个文件最多10MiB、最多24000字符，PDF最多50页，扫描文档不含OCR。
不会执行宏/脚本或访问文档外链；文件按用户与助手隔离，通过注册文件编号读取。
Word只提取正文段落与表格。压缩炸弹、活动内容、符号链接、硬链接及越界路径拒绝。

本插件为 MioBot 的薄集成代码，AGPL-3.0-only；保留 AstrBot、pypdf 和 python-docx
在发行包中的原始许可证。不包含API访问权限、用户文件或模型训练。
