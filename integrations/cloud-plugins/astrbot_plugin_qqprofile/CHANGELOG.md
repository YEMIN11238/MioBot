# 更新日志

## v1.1.6-owner-avatar.2 (2026-10-29)

- 将头像工具与命令分别注册。LLM 工具返回明确文本，避免 MessageEventResult 被框架转换为模糊的空结果后，模型误报成功。
- 没有当前附图或引用图时明确返回“未执行”。读取失败、网关失败、网关接受分别反馈；网关接受不等同于 QQ 已显示新头像。
- 记录不包含图片内容和访问链接的执行阶段，便于核查实际操作结果。

## v1.1.6-owner-avatar.1 (2026-10-29)

- 设置头像时复用 AstrBot 的图片解析器，以 OneBot `base64://` 传输图片内容，兼容 AstrBot 与 QQ 网关分别运行在不同容器的部署。
- 人格头像缓存复用本次读取的图片内容；同步缓存头像时也使用内联图片，避免把 AstrBot 本地路径传给网关。
- 优先使用当前消息附图，其次使用引用消息中的图片。仅管理员可操作，网关返回成功后才确认更新。
