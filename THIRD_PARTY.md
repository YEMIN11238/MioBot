# Third-party components

- AstrBot v4.29.3 — https://github.com/AstrBotDevs/AstrBot — upstream revision f61a7f42696da6df25dc7a249ec9b8d54ed9da18. AGPL-3.0-or-later. The app uses the native desktop authentication and HTTP API. This is a **modified managed runtime**, not an unmodified upstream distribution: patch `miobot-managed-outbound-tools-v1` makes automatic `send_message_to_user` injection conditional on `MIOBOT_DISABLE_NATIVE_OUTBOUND_TOOLS`; MioBot sets this flag to `1`. Standalone AstrBot retains upstream behavior when that flag is absent. MioBot's synchronized configuration also disables native cron tools, keeping reminder confirmation and outbound delivery under the app's control. The reproducible patch is in `server/assistant-runtime.mjs` and `scripts/patch-managed-runtime.mjs`, and is applied during managed setup/packaging. The local source checkout, dependency lock generated during setup and packaging script are available with this project. The bundled runtime retains its original LICENSE.
- LivingMemory 2.8.2 — https://github.com/lxfight-s-Astrbot-Plugins/astrbot_plugin_livingmemory — author lxfight; original AGPL v3 license retained in `integrations/livingmemory/astrbot_plugin_livingmemory/LICENSE`. The existing memory engine is bundled with a narrow integration hardening in `core/utils/__init__.py`: unresolved personas fail closed when MioBot sets `MIOBOT_REQUIRE_MEMORY_PERSONA=1`. Without that flag, the original behavior is retained. Eleven original translation/prompt resources omitted from the audited snapshot were restored from the upstream 2.8.2 release commit `a1e9c20a8c5fab93d6143f51be26fb1bbf8143ec`. Provenance, modifications and scope are recorded in `integrations/livingmemory/NOTICE.md`. No upstream runtime database, credentials or user memory are included.
- PrismarineJS `minecraft-data` 3.119.0 — https://github.com/PrismarineJS/node-minecraft-data — MIT, as declared in the retained upstream package metadata. Underlying game data: https://github.com/PrismarineJS/minecraft-data. MioBot includes a selected offline Minecraft Java Edition 1.21.8 item/block/recipe snapshot, not a Minecraft game client or a live server.
- PrismarineJS `prismarine-recipe` 1.5.0 — https://github.com/PrismarineJS/prismarine-recipe — MIT, as declared in the retained upstream package metadata. Used during data export to calculate shaped/shapeless recipe ingredients and crafting-table requirements. Runtime queries use the exported snapshot. Both packages' original metadata/READMEs, MIT declarations and standard terms are retained under `integrations/game-data/`; exact versions, npm integrity values, transformation and snapshot SHA-256 are in `integrations/game-data/PROVENANCE.json`. Neither npm package shipped a separate LICENSE text; `integrations/game-data/LICENSE` explains this distinction. The underlying data repository README and its source attribution are also retained.
- Electron — MIT; version locked in package-lock.json. Original license/notices are retained in the Electron distribution.
- React, React DOM — MIT; version locked in package-lock.json.
- Lucide — ISC; version locked in package-lock.json.
- react-parallax-tilt 1.7.349 — https://github.com/mkosir/react-parallax-tilt — MIT. Used for the sidebar mascot's CSS perspective/tilt; license retained in licenses/react-parallax-tilt.LICENSE.
- CPython 3.12.15 (python-build-standalone distribution managed by uv) and its dependencies — original license files retained in the bundled Python directory.
- AstrBot Python dependencies — versions in the local runtime uv.lock; individual dist-info licenses retained in bundled packages.

The short-reply formatting, assistant presets, bounded opt-in care scheduler, Minecraft bridge plugin and `minecraft-guide` Skill are MioBot implementation code/instructions. Personality enhancement additionally uses the attributed Humanizer plugin described below. The Minecraft bridge and Skill use the attributed fixed dataset and do not control a running game.

OpenAI-compatible chat/embedding endpoints, Gemini, Anthropic and other configurable model services are external services rather than bundled model weights. Long-term memory embeddings use a separately configured `text-embedding-3-small` provider; summaries use the selected chat provider. Their API use, including opt-in care generation, may incur provider charges. The integration does not include paid API access or provider credentials.

No SnowLuma, QQ client, personal account state, API key, or preexisting conversation is included in the app bundle. The pinned upstream AstrBot source can also be obtained from https://github.com/AstrBotDevs/AstrBot/tree/v4.29.3 . MioBot's managed modifications described above remain available in this project's source and patch script.

## Managed personality plugin

- SIiOC `astrbot-plugin-humanizer` / `astrbot_plugin_wanna_be_human` 4.1.9 — https://github.com/SIiOC/astrbot-plugin-humanizer — pinned commit `38e732119b309164636671cb715c7a43575b68a7`, AGPL-3.0. Original source and LICENSE are retained under `integrations/humanizer/astrbot_plugin_wanna_be_human/`. MioBot integration revision `miobot.1` adds fail-closed persona/sender/session scope keys, disables duplicate scheduling/delivery and automatic auxiliary model features, preserves truthful AI/knowledge disclosures and code, and selects a fixed generic expression reference. Changes are limited to the managed environment flag `MIOBOT_MANAGED_PERSONALITY=1`; provenance, precise modifications and verification limits are recorded in `integrations/humanizer/NOTICE.md` and `UPSTREAM.json`. The upstream README credits Humanizer-zh and stop-slop as rule origins; those attributions are preserved. No voice, stickers or user corpus is added, and no new optional dependency is installed.

- zexuan604 / zexuanw958-svg `astrbot_plugin_dafeiyu_clean` — from the video configuration pack https://github.com/zexuanw958-svg/dafeiyu-config-pack at locally recorded revision `8c01b0361b8a4baff5be3d2bc67ed55108953086`. Original plugin folder has no separate license file; the containing pack explicitly declares MIT for its own code/persona/settings. That original LICENSE and untouched source are retained in `integrations/dafeiyu-clean/`. MioBot version `v0.1.1-miobot` adds WebChat/native 4.29.3 compatibility, profile gating and normal-code preservation. Exact origin, hashes and modifications are in `NOTICE.md` and `PROVENANCE.json`. No voice or stickers are part of this plugin.
