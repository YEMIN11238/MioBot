## 从软件中使用

1. 在「设置 → 消息渠道」配置 QQ 网关，指定主人私聊接收位置，完成测试发送并确认收到。
2. 打开「扩展 → 大肥鱼同款组件」，选择组件与已验证的 QQ 渠道。组件随软件提供，不需额外下载 ZIP。
3. 按需调整高级参数，声音凭据填写在独立密码框。保存后不会回显凭据，配置 JSON 与普通状态中不保存其原值。
4. 点击「保存并启用」。软件等待回复结束后才允许操作，并重启托管后台；通过原生插件列表检查实际加载结果。失败时恢复原配置并尝试恢复原后台。
5. 在所选 QQ 私聊验证实际行为。语音、唱歌和学习可能调用额外服务；有效凭据、额度及 QQ 登录态仍需自己配置。

每个组件绑定一个渠道对应的助手。主人身份由已验证渠道自动生成，不沿用旧账号或 UMO。启用中的组件须先停用，才能修改其绑定渠道并重新验证。B站收集器要求同渠道先启用原生图库。

## 默认行为与边界

- 九个新增组件默认仅内置代码，不参与普通聊天；启用后才加载原生目录。停用会保留其插件数据，未覆盖自装或手动改过的同名源码。
- QQ 资料／空间等工具只给主人的精确 QQ 私聊配置，其他私聊、群聊、电脑与手机网页不会获得这些权限。群转发只绑定明确填写的来源群，目标为空时不会扩展为全部群。
- QQ 自动收集默认关闭。开启后只收匹配主人会话且带平台表情标记的图片；普通照片及未标记截图不进入收集。不会复制主人原有专属图库。
- 学习的独立 WebUI、自动前端构建和自动安装依赖关闭，不另开后台端口。原生人格自动应用在托管模式下关闭，避免覆盖 MioBot 人设。
- Qzone 图卡可选依赖缺失时降级文字；非标准 JSON5 缺相应解析器时如实报错。R2 存储需要可选 `minio`，未配置时不加载它。GPU 唱歌服务、UVR5、模型权重不因安装这些组件而下载。
- 此次组件主要用于 QQ 原生消息链。MioBot 电脑／手机 Web 的媒体仍走现有媒体桥，原生图库与应用图库不会自动合并；不声称 WebChat 已消费所有原生音频／图片事件。
- 没有复制旧 API Key、QQ 登录态、聊天、记忆数据库、私人样音或个人图库；也没有自动购买服务或发送公开空间内容。
